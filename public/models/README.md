# ទីតាំងដាក់ File 3D (.glb / .gltf)

ថតនេះសម្រាប់ផ្ទុកឯកសារម៉ូដែល 3D ទាំងអស់នៃហ្គេមទេសចរណ៍ 3D របស់អ្នក៖

## 1. ផែនទី និងបរិស្ថាន (Map & Environment)
- **ទីតាំង:** `public/models/map/angkor-world.glb`
- **ប្រើសម្រាប់:** ផែនទីកម្ពុជា ប្រាសាទ អគារ ផ្លូវ និងទេសភាព។
- **ទម្រង់ណែនាំ:** `.glb` (Binary GLTF)។

## 2. តួអង្គ និងចលនា (Characters & Animations)
- **ទីតាំង:** `public/models/characters/player.glb`
- **ប្រើសម្រាប់:** តួអង្គទេសចរណ៍ (Player Avatar) ដែលមាន Rig/Skeleton និង Animations ដូចជា `Idle`, `Walk`, `Run`, `Jump`។
- **ប្រភពណែនាំ:** ទាញយកពី [Mixamo.com](https://www.mixamo.com/) (ជ្រើសយក FBX with Skin រួច Convert ឬ Export ជា .glb តាម Blender)។

## 3. មធ្យោបាយធ្វើដំណើរ (Vehicles)
- **ទីតាំង:** `public/models/vehicles/tuk-tuk.glb`
- **ប្រើសម្រាប់:** ម៉ូតូកង់បី (Tuk-Tuk/Remork) ឬទូកសម្រាប់របៀបបើកបរ។

## 4. វត្ថុតុបតែងបរិស្ថាន (Environment Assets)
- **ទីតាំង:** `public/models/environment/tree.glb`
- **ប្រើសម្រាប់:** ដើមឈើ ផ្កា ផ្ទាំងថ្ម និងវត្ថុតុបតែងតូចៗ។

> **ចំណាំ:** ប្រសិនបើអ្នកមិនទាន់បានដាក់ File `.glb` នៅឡើយ ប្រព័ន្ធនឹងបង្ហាញ Fallback 3D Model ស្វ័យប្រវត្តិដើម្បីកុំឱ្យខូច Canvas និងឱ្យអ្នកអាចលេងភ្លាមៗបាន!
